Supervertaler Workbench

A free, open-source CAT tool of its own. Import a file, translate it with AI, translation memory, terminology and QA, and export it back out with the formatting exactly as it came in.

Download for Windows Help Free and open source, with no account and no licence. On macOS and Linux, install it with pip install supervertaler.

In active development again. After a quiet spell while Supervertaler for Trados and for memoQ took shape, Workbench is getting regular releases again, with new features as well as fixes. Version 1.10.372 alone closed 22 issues from the tracker: your own segmentation rules, placeholders treated like tags, saved QA checks, LanguageTool, and a sample project to try it all out on. Ideas and bug reports are welcome on GitHub.

A CAT tool of its own, or a plugin?

A standalone CAT tool has to do one thing above all else: import a file, let you translate it, and export it back out with the formatting exactly as it came in – for every format a client might send. Workbench leaves that to the Okapi framework, an open-source file-processing toolkit also used by other translation tools, and puts AI translation, translation memory, terminology and QA on top of it. It runs on Windows, macOS and Linux.

Supervertaler for Trados and for memoQ take the other route: they let the CAT tool you already use handle the files, and add the AI translation, terminology and search tools inside it. If you work in Trados or memoQ, they are the natural choice; if you would rather have a CAT tool of your own, free and open source, that is Workbench.

Download

Windows

Download the latest release from GitHub, unzip it and run Supervertaler.exe from the folder.

macOS and Linux

Install it from PyPI with pip install supervertaler, on Python 3.10 or later, then start it with supervertaler.
