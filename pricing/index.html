Already a subscriber?

Then you already have both. If you subscribed for Supervertaler for Trados, the same licence covers Supervertaler for memoQ – install it and there is nothing more to buy.

On a computer where the Trados plugin is already activated, the memoQ plugin picks up your licence by itself. On any other computer, enter the same licence key. Both plugins on one computer count as one of your two computers, not two.

Where the licence key goes

After you subscribe, your licence key arrives by email. Enter it once per computer.

In Trados Studio

Install the plugin from the RWS App Store. Then click the gear icon on the TermLens or Supervertaler Assistant panel, open the Licence tab, paste the key and click Activate.

For memoQ

Download the installer and run it with memoQ closed. Then open Supervertaler for memoQ from the Start menu, choose Help, Licence, paste the key and click Activate.

Questions

Do I need a subscription for each plugin?

No. One licence covers both, and every feature of both, including everything added later.

How many computers?

Two – a desktop and a laptop, say. To move the licence to a new computer, deactivate it on the old one first, from the same Licence window you activated it in.

What happens when the trial ends?

Your termbases, prompts, memory banks and settings are all kept. Subscribing unlocks everything again straight away. The trial belongs to the computer rather than the plugin, so both plugins share it.
