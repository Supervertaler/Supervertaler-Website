Privacy Policy

Last updated: 28 October 2026

The short version: Supervertaler does not collect, store, or transmit your data to Supervertaler servers. Your translations, termbases, and documents stay on your machine. When you choose to use AI features, data is sent directly from your computer to the AI provider you selected, using your own API key. We never see it.

This policy covers Supervertaler Workbench (the desktop application), Supervertaler for Trados (the Trados Studio plugin) and Supervertaler for memoQ (the memoQ plugin, covered in section 7). We know that as a professional translator you often work with confidential client material, and we have designed our software with that in mind.

What you agree to when you use the software – your licence, subscriptions and refunds, and what you are responsible for when you use AI – is in the terms of use.

1. Data that stays on your machine

The following data is created and stored locally on your computer only. It is never transmitted anywhere:

  • Translation files – your SDLXLIFF, DOCX, and other documents remain entirely on your local file system
  • Termbases – your Supervertaler glossary databases (.db files) and MultiTerm termbases (.sdltb files)
  • Translation memories – all TM data stays local
  • Settings and preferences – stored in your local AppData folder
  • Chat history – AI Assistant conversations are held in memory only during your session and are never written to disk

2. Data sent to AI providers (only when you use AI features)

When you use the AI Assistant, Batch Translate, or single-segment AI translation, data is sent to the AI provider you have chosen and configured. This only happens when you explicitly trigger an AI action – never in the background.

What is sent

Depending on the feature and your settings, the following may be included in AI requests:

  • Source text segments (the content you are translating)
  • Target text segments (your existing translations, for context)
  • Terminology from your termbases (source/target term pairs)
  • Translation memory matches (if enabled in AI Context settings)
  • Surrounding segments for document context (configurable)
  • Project and file name, source/target language pair
  • Images you attach in the AI Assistant chat
  • Your chat messages and conversation history (current session only)

Where it is sent

Provider Destination Your data is governed by
OpenAI api.openai.com OpenAI API Data Usage Policy
Anthropic (Claude) api.anthropic.com Anthropic Privacy Policy
Google (Gemini) generativelanguage.googleapis.com Google Gemini API Terms
Ollama (local) localhost (your own machine) No data leaves your computer
Custom endpoint Server URL you configure That provider's terms

For maximum confidentiality: If you work with sensitive or NDA-protected content and want AI features without any data leaving your machine, use Ollama as your provider. All processing happens locally on your own hardware.

What is NOT sent to AI providers

  • Your full documents – only the segments relevant to your current request
  • Your API keys for other providers
  • Your license key or account information
  • Any data from other projects or files not currently open

3. API keys

Your AI provider API keys are stored locally in your settings file (%LocalAppData%\Supervertaler.Trados\settings.json). They are sent only to the respective AI provider when making API calls. Supervertaler never transmits your API keys to any other destination.

4. Update checks

Supervertaler for Trados is installed and updated through the RWS AppStore. To tell you when a new version is out, it downloads the AppStore's public list of plugins from RWS (api-appstore.rws.com) when you open the Trados Studio editor, at most once a day, and compares the versions on your computer. The request carries only a generic user-agent (Supervertaler-Trados-UpdateCheck/2.0) – nothing about you, your computer or your work. If you choose Install Update, the update is downloaded from the same RWS AppStore. You can skip a version or postpone the reminder, and nothing is ever installed unless you choose to.

Setting up ChatGPT desktop from Connect AI assistant in the plugin's AI settings downloads the connector program from Supervertaler's releases on GitHub (api.github.com and github.com). Those requests also carry only a generic user-agent, and are made only when you click the button.

Supervertaler Workbench looks for a new version only when you choose Check for Updates. It asks GitHub (api.github.com) for the latest release, and the request carries only the program's name and version.

The memoQ plugin's update check is described in section 7.

5. License validation

If you have a paid subscription, your license is validated through Lemon Squeezy (api.lemonsqueezy.com). The only data sent is:

  • Your license key
  • An anonymous machine identifier (a one-way hash – it cannot be reversed to identify your computer)

No translation content, file names, or personal information is included in license checks.

Trial registration (Trados plugin v18/19.20.118 and later; memoQ plugin 0.1.1 and later)

If you are using the free 14-day trial (no licence key), the plugin registers the trial once per session on startup with a first-party licence endpoint (a Cloudflare Worker operated by Supervertaler). The only data sent is:

  • The same anonymous machine identifier used for licence activation (a one-way hash – it cannot be reversed to identify your computer)
  • Plugin version, Trados Studio or memoQ version, and system locale
  • The trial's locally recorded start date and status

This gives the trial's start date one reliable, authoritative record, so the trial behaves consistently across reinstalls, data-folder moves, and clock changes. It is part of how the trial functions – not analytics – so it is separate from the opt-in usage statistics described below. The country code is derived from the network connection by Cloudflare; no IP addresses are stored. The trial is one per computer, shared by both plugins, so the record also notes which of the two plugins that computer has used. Trial records are kept only while relevant to licensing and are purged after a period of inactivity. If the endpoint cannot be reached (no internet, firewall, air-gapped machine), the trial keeps working normally.

6. Optional anonymous usage statistics

Supervertaler for Trados sends anonymous usage statistics unless you switch them off. On first launch, a dialog explains what is sent and offers Keep it on or Turn it off; closing the dialog keeps them on. You can switch them off at any time in Settings. While they are on, a single lightweight ping is sent once per session on plugin startup. The only data sent is:

  • A random anonymous ID (generated locally, not tied to any account or identity)
  • Plugin version
  • OS version
  • Trados Studio version
  • System locale
  • Whether Windows is running in a virtual machine, and which kind (for example Parallels, which usually means a Mac)
  • Processor architecture (for example x64)
  • Display scaling, Windows text size and the plugin's own interface scale, as percentages

The country code is derived from the network connection by Cloudflare (the hosting provider) – no IP addresses are stored. No personal data, translation content, termbase information, or feature usage is ever collected. The data is sent to a first-party Cloudflare Worker endpoint – no third-party trackers are involved.

You can change your choice at any time in Settings. If the ping fails (no internet, firewall, etc.), nothing happens – no retries, no queuing, no error messages.

Supervertaler for memoQ has usage statistics from version 0.1.1, but asks first: nothing is sent unless you agree, and it sends fewer fields. See section 7.

7. Supervertaler for memoQ

The memoQ plugin follows the same principles: your own API key, your documents never passing through a Supervertaler server, and nothing sent anywhere except the connections listed here.

AI translation

memoQ asks Supervertaler for a translation when you move to a segment, and when you run Pre-translate with Supervertaler as the machine translation engine. Each request goes to the AI provider you configured (Anthropic, OpenAI or Google, or the endpoint you entered) using your own API key, and may include:

  • The segments being translated
  • Segments you have already confirmed in the same document, as examples to follow
  • The best fuzzy match from your translation memory, if you have set memoQ to forward it to Supervertaler
  • Terms from your glossary and termbases that occur in the segment
  • The prompt you selected, the memory bank for the client, and memoQ's project details (client, domain and subject)
  • List numbering read from the original document, and the figure descriptions saved for the project

Two actions in the companion editor send more, and only when you click them: AutoPrompt sends the source text Supervertaler has seen, with your confirmed segments and glossary, so the AI can draft a prompt; and Describe images with AI sends the document's images so the AI can describe them. The settings also ask your provider, with your API key, for the list of models it offers.

AI assistants (Claude Desktop, ChatGPT desktop)

The plugin runs a small server that only programs on your own computer can reach. If you connect an AI assistant to it, the assistant can read the open document, your confirmed segments, glossary, prompts and memory banks, and what it reads is sent to that assistant's provider under your own account with them – Anthropic for Claude, OpenAI for ChatGPT. Nothing is shared this way unless you connect an assistant and ask it to do something. The live document link, which tells the assistant where you are in memoQ, also talks only to memoQ on your own computer.

Setting up ChatGPT desktop from the editor downloads the connector program from Supervertaler's releases on GitHub (api.github.com and github.com). That request carries only a generic user-agent (Supervertaler-for-memoQ).

Licence

The memoQ plugin uses the same Supervertaler licence as the Trados plugin, validated through Lemon Squeezy as described in section 5: your licence key and the same anonymous machine identifier, nothing else. From version 0.1.1, while there is no licence key, the free trial is registered as described in section 5: the same anonymous machine identifier, the plugin and memoQ versions, your system locale and the trial's start date and status.

Optional anonymous usage statistics (0.1.1 and later)

The first time you open the Supervertaler editor, it asks whether the memoQ plugin may send anonymous usage statistics. Nothing is sent unless you answer yes, and you can change your answer at any time under Settings, Translation settings. If you agree, one small message is sent each time memoQ starts, to the same first-party endpoint as the Trados plugin's statistics. The only data sent is:

  • A random anonymous ID (generated locally, not tied to any account or identity)
  • Plugin version
  • Windows version
  • memoQ version
  • System locale

The country code is derived from the network connection by Cloudflare; no IP addresses are stored. No documents, translations, terminology, file names or feature usage are ever included.

Update check (0.1.2 and later)

Once a day, the plugin or the Supervertaler editor asks GitHub (api.github.com) which version of Supervertaler for memoQ is the latest, so it can tell you when a new one is available. The request carries only a generic user-agent (Supervertaler-for-memoQ) – nothing about you, your computer or your work. If you choose Download and install, the installer is downloaded from GitHub, and it is checked against the size and checksum GitHub lists before it runs. You can skip a version, and nothing is ever installed without you choosing to.

What the memoQ plugin does not send

  • Nothing about you or your work with the update check
  • No usage statistics unless you agree to them, as above
  • No translation content to anyone except the AI provider or assistant you chose

What it keeps on your computer

To learn from your work, the plugin keeps the source segments it has seen, the segments you confirmed and the translations it has already produced, together with its settings and a log. They are stored in your Supervertaler data folder and in C:\Users\<you>\AppData\Local\Supervertaler.memoQ\, and are never transmitted. The log names the projects and files you open, so check it before sending it to anyone. Forget stored context in the plugin's options removes what it has learned. API keys are stored locally; if you also use Supervertaler for Trados, the memoQ plugin can use the keys you saved there, so you only have to change a key once.

8. What we do NOT do

  • We do not collect data without your explicit consent
  • We do not track which features you use, what you translate, or what termbases you open
  • We do not use cookies. We count page views on this website and on docs.supervertaler.com with Cloudflare Web Analytics, which sets no cookies and does not identify or follow individual visitors
  • We do not sell or share any data with third parties
  • We do not have access to your translations, termbases, or documents

All Supervertaler products have their source code publicly available on GitHub. You can verify every network call the software makes by inspecting the code yourself:

10. Your responsibilities

When you use AI features with cloud-based providers (OpenAI, Anthropic, Google), the text you send is processed by those providers under their own privacy policies. If you are bound by NDAs or confidentiality agreements with your clients, please:

  • Review the data handling policy of your chosen AI provider
  • Consider using Ollama for fully offline, local-only AI processing
  • Adjust AI Context settings to limit what data is included in requests (e.g., disable TM matches or restrict the number of context segments)
  • Consult with your client if in doubt about whether AI-assisted translation is permitted

11. Contact

If you have questions about this privacy policy or how Supervertaler handles your data, please contact us at support@supervertaler.com.

12. Changes to this policy

We will update this page if our data practices change. The date at the top of this page indicates when the policy was last revised.
